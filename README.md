# Java Time Explorer

## Project Description

Java Time Explorer is a Java console application that demonstrates different date and time operations using Java's built-in Time API.

The program allows users to work with dates, calculate time differences, convert time zones, and view Unix timestamps through a simple menu-driven interface.

## Features

The application includes eight features:

1. **Show Current Date and Time** – Displays the current date, time, and date-time.
2. **Format a Date** – Converts dates into multiple readable formats.
3. **Parse a Date from Text** – Reads a date entered as text and converts it into a LocalDate object.
4. **Calculate Age or Event Difference** – Calculates the years, months, and days between two dates.
5. **Countdown to a Future Date** – Calculates how many days remain until a future date.
6. **Calculate Time Duration** – Calculates the time between two dates and times.
7. **Convert Time Zones** – Converts a date and time between different time zones.
8. **Show Current Timestamp** – Displays the current Unix timestamp in seconds and milliseconds.

## How to Run

1. Clone or download this repository.
2. Open the project in IntelliJ IDEA.
3. Open `Main.java`.
4. Run the Main class.
5. Select an option from the menu.
6. Follow the prompts displayed in the console.

## Example Input Formats

- Date: `YYYY-MM-DD`
- Date for parsing: `MM/dd/yyyy`
- Date and time: `YYYY-MM-DDTHH:MM`
- Time zones: `America/Chicago`, `America/New_York`, `Europe/London`


## Purpose

The purpose of this project is to practice Java programming, user input, methods, exception handling, date and time calculations, and working with Java's built-in date and time classes.
